# lab

My workshop. Small programs, built by hand, to actually learn the languages
and tools I've only read about.

## Rule
Every project here is written from scratch, by me, without AI writing the
code. AI is allowed only *after* a thing works, as a reviewer. "Done" means:
I can rebuild it in a blank editor and explain why each part is there.

## Layout
- `rust/`     — Rust book projects → toward an emulator
- `c/`        — C, the slow burn: memory, syscalls
- `asm/`      — reading x86-64, godbolt notes
- `re/`       — crackme write-ups (no binaries committed)
- `go/`       — DevOps tooling
- `ai/`       — retrieval + agents, from scratch
- `physics/`  — simulations
